# 华电教务 App(NcepuJw)

一个非官方的华北电力大学教务系统 Android 客户端,顺带集成了校园生活服务(慧生活798 直饮水、U净洗衣机/烘干机)。

> ⚠️ **免责声明**
> 本项目与华北电力大学及上述任何服务商均无关联,纯属个人自用作品,**仅供个人学习使用**,请勿用于商业用途,也请勿高频请求给学校服务器增添负担。
> 账号密码等凭据只保存在本机(SharedPreferences),不上传任何服务器;但由此产生的账号风险请自行评估。

> 🧪 **Vibe Coding**
> 本项目几乎全部代码由 AI 生成,没有经过完整的测试与安全审计,也不保证长期可用。请当作学习与自用的实验品看待。

## 功能

### 教务
- **登录**:教务密码直登,或统一身份认证(账号密码 + 短信验证码),两种方式凭据互不覆盖,可记住密码自动登录;不想登录也可以跳过,不影响生活服务
- **课表**:一次抓取整学期、本地按周展示,左右滑动无缝切周;今日列高亮、正在上的课带描边;同课程同色;表头显示日期与节次时间
- **成绩**:按学期查询,自动算加权平均分、绩点、总学分(首次查看前需在网页/内置 WebView 完成评教)
- **考试安排**:按学期查询,考前可提醒
- **培养方案**、**选课中心**:选课/评价等操作跳内置 WebView,自动复用登录状态
- **上课提醒**:按课表精确闹钟,提前 0/5/10/15/20 分钟可调
- **校外模式**:不在校园网也能用教务(走学校 WebVPN 隧道),每次新建会话需输一次短信验证码

### 校园生活
- **主页扫码**:扫机身二维码自动分辨洗衣机 / 饮水机,分别进入对应页面
- **饮水机(慧生活798)**:手机号 + 短信验证码登录;设备列表、一键开关水;扫码或手动输入设备编号添加
- **洗衣 / 烘干(U净)**:手机号 + 短信验证码登录;扫码识别设备并自动区分洗衣机与烘干机;选套餐/程序、下单、支付宝支付、进度轮询、启停;已扫设备本地保存并可加备注;出故障时直接显示原因与处理办法,修好后可点「继续洗衣」接着洗完;洗衣/自洁完成推送通知
- **相机扫码**:基于 CameraX + ML Kit,支持 QR 码与 DataMatrix

### 外观与体验
- **Material You 动态取色**(Android 12+,可关闭),另有多套预设配色
- 深浅色三档:跟随系统 / 浅色 / 深色
- **底栏形态可选**:标准或悬浮,材质支持实色 / 高斯模糊
- **自定义课表背景图**:拖动 + 双指缩放裁剪,模糊强度与暗化程度可调
- 文本大小、节次上课时间可自定义,周起始日可设置
- 应用内自动更新(有新版本会提示)

## 已知限制

- 饮水机、洗衣机的余额与价格以官方 App 为准;U净支付依赖支付宝
- 校外模式半自动:每次新建隧道会话需输一次短信验证码
- 教务系统为学校当前的老版部署,若学校升级接口,相关功能会失效
- Vibe Coding 产物:没有完整测试,界面与流程以自用为主,遇到问题请自行核对
